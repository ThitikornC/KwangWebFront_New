## กติกา: แก้ไฟล์ที่ลอกมาให้น้อยที่สุด

`src/pages/BuuStudent8bitV2.jsx` และ `src/lib/*` คัดลอกมาจากต้นทาง เวลาต้นทางอัปเดต
ให้ก๊อบทับได้เลย

**จุดเดียวที่แก้ในไฟล์ที่ลอกมา** คือแถบหัวแอป (ราวบรรทัด 3425) มีสองเรื่องอยู่ในบล็อกเดียวกัน:

1. ตัดชื่อ ม.บูรพา ออก เหลือ `MomayforStudent` เดิมเป็น `Momay x สำนักหอสมุดม.บูรพา | For Student`
2. จัดชื่อให้อยู่กลางแถบ — ต้นฉบับเป็น flex + `space-between` ชื่อจึงชิดซ้าย
   (ไม่เป็นปัญหาตอนชื่อยาว) เปลี่ยนเป็นกริด `minmax(0,1fr) auto minmax(0,1fr)`
   โดยช่องซ้ายเป็นช่องเปล่าถ่วงน้ำหนักกับกลุ่มนาฬิกา+กระดิ่งฝั่งขวา

มีคอมเมนต์กำกับไว้ในไฟล์ทั้งสองจุด **ก๊อบทับเมื่อไหร่ต้องมาแก้ซ้ำ**

ที่เหลือทำจาก **ข้างนอก** ทั้งหมด:

| ต้องการ | ทำที่ไหน |
|---|---|
| ไม่มี gateway ของ BUU ให้ยิง | `src/mockGateway.js` ดักที่ `window.fetch` |
| รูปโซนโหลดจาก `<img src=".../api/assets/<คีย์>">` ซึ่งไม่ผ่าน fetch | `installAssetShim()` ใน `mockGateway.js` ดักตอน `src` ถูกเซ็ต แล้วสลับเป็น data URL |
| ไอคอนอ้างพาธ `/icons/*.png` | build → ตรงกับ `public/icons/` ของ Nuxt · dev → middleware ใน `vite.config.js` |
| ฟอนต์ Press Start 2P / Sarabun | `index.html` |
| หน้าเดิมไม่มีส่วนแสดงเรื่องพลังงาน | `src/components/AutoPowerPanel.jsx` วางทับเป็นแผงลอย |

ถ้าจะอัปเดตหน้านี้จากต้นทาง: ก๊อบไฟล์ทับ แล้วเช็คว่า endpoint ที่มันเรียกยังครบใน
`mockGateway.js` หรือเปล่า (ดูรายการ `routes` ท้ายไฟล์)

## ข้อมูล

ไม่ต่อ API จริง — `mockGateway.js` สร้างข้อมูลจากผังห้องสมุด 5 ชั้น 20 พื้นที่
(ชุดเดียวกับที่หน้าขาย `MomayforSaleV2` ใช้เล่าเรื่องแอปนี้) แล้วตอบกลับเป็น:

- `/api/config` → ห้อง + กล้อง + ความจุ
- `/api/camera-counts` → จำนวนคนสด ๆ ราย-กล้อง
- `/api/camera-density` → ประวัติ 7 วัน ราย 30 นาที
- `/api/bookings`, `/api/ratings`, `/api/usage` → ตอบว่างไว้

รูปที่ผู้ใช้อัปโหลดรายโซนไม่ได้อยู่ในรายการข้างบน เพราะหน้า STUDENT ไม่ได้ดึงผ่าน fetch
แต่ใส่ลง `<img src>` ตรง ๆ — `installAssetShim()` จึงดักที่ `HTMLImageElement.prototype.src`
และ `Element.prototype.setAttribute` แล้วสลับ `/api/assets/<คีย์>` เป็น data URL แทน
(ฝั่ง gateway ตั้งคีย์เองใน `buildRooms` แล้วส่งเข้าหน้าทาง `room.heroImgs`)

## เชื่อมกับหน้า MOMAY Surprise

ผู้ใช้ที่เลือกหมวด **ห้องสมุด** ในหน้า `/MomaySurpriseOrganize` แล้วกดปุ่มกลาง
จะถูกส่งมาที่นี่พร้อมคำตอบทาง query string:

```
/momay-student/?o=library&p=1200&c=300&e=78000&s=people,parking&k=midday
```

หมายเหตุ: หน้า `/MomaySurpriseOrganizeV2` บังคับให้กรอก **จำนวนที่นั่งทุกโซน** ก่อนไปต่อ
เพราะที่นั่งคือตัวหารของแถวโซนในหน้านี้ — มีที่นั่งจึงจะขึ้นเป็น "คนที่ตรวจจับได้ / ที่นั่งทั้งหมด"
ไม่มีที่นั่ง (ความจุ = 0) หน้าเดิมจะตกไปโชว์เป็น % แทน ซึ่งอ่านแล้วไม่รู้ว่าเต็มแค่ไหน

ถ้าผู้ใช้กรอกผังอาคารเอง (จำนวนชั้น / โซน / รูป / ที่นั่ง / เวลาเปิด-ปิด / ควบคุมเครื่องใช้ไฟฟ้า)
ข้อมูลชุดนั้นจะถูกเก็บไว้ใน `localStorage` คีย์ `momay:library-setup` เพราะมีรูปติดมาด้วย
ส่งทาง URL ไม่ไหว — `mockGateway.js` อ่านคีย์นี้ก่อนเสมอ ถ้าไม่มีจึงค่อยใช้พารามิเตอร์ใน URL
แล้วสุดท้ายจึงตกไปที่ผังตั้งต้น

**ข้อจำกัด:** localStorage อยู่กับเบราว์เซอร์เครื่องนั้น ส่งลิงก์ให้คนอื่นเปิดจะได้ผังตั้งต้น
ถ้าต้องแชร์ได้ต้องย้ายไปเก็บใน DB แล้วส่ง id ผ่าน URL แทน

`mockGateway.js` อ่านพารามิเตอร์เหล่านี้ แล้วคำนวณด้วย
`utils/momaySurpriseOrganize/model.ts` — **โมเดลตัวเดียวกับหน้า Surprise** —
เพื่อให้ได้ตัวคูณความหนาแน่น แล้วเอาไปปรับจำนวนคนในทุกพื้นที่ทั้งอาคาร
ตัวเลขสองหน้าจึงเล่าเรื่องเดียวกันเสมอ

หมวดอื่นที่ไม่ใช่ห้องสมุดส่งมาก็ไม่แปลผล จะใช้ตัวเลขตั้งต้นของผังแทน
